Power BI Dashboard – Bank Loan Analysis

This folder contains the interactive Power BI dashboard developed for the Bank Loan Analysis project.

Skills Applied
  * Data Visualization
  * Power Query
  * Data Transformation
  * DAX Measures
  * KPI Cards
  * Interactive Slicers

Dashboard Objectives
  * Monitor overall loan performance.
  * Analyse loan status distribution.
  * Understand customer credit profiles.
  * Identify potential credit risks.
  * Present key business insights through interactive visualizations.
