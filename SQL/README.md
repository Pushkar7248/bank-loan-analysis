SQL Analysis – Bank Loan Analysis

This folder contains PostgreSQL queries used for analysing bank loan data.

Skills Applied
  * PostgreSQL
  * SELECT, WHERE, GROUP BY, ORDER BY
  * Aggregate Functions
  * CASE Statements
  * Common Table Expressions (CTEs)
  * Subqueries
  * Window Functions
  * RANK() and Filtering
  * Credit Risk Analysis

Objective
To perform detailed loan analysis, evaluate repayment performance, identify high-risk loan segments, and generate meaningful business insights using SQL.
